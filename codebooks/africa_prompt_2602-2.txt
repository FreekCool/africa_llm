2. politics


Binary variable: either 0 or 1, where 1 indicates that the post is about politically relevant content. 


Use the following guidelines when deciding whether the post is about politics:
A post should be considered as politically relevant (so be coded as  1) if:
It’s about any political issue, (potentially) politically relevant topics (including conspiracy theories) are being discussed, such as science, immigration, civil liberties, labor, law & crime, international affairs, education, healthcare, housing, etc.
It’s about a politically relevant (or historical) event/s, political actor/s
It is about development issues, infrastructure or the distribution of resources 
0 otherwise (not politically relevant)
Unpolitical are posts about the person’s family, hobbies, and similar unless they are discussed in a political context, eg if the president takes place in a run to promote health policies then this is political
Posts about the beauty of the country are only unpolitical if they contain no reference to specific localities/regions or issues, eg it is political if it discusses wildlife preservation or that one locality/region in particular is beautiful 
Code as 99 if unclear 


Note1: Please code politics inclusively, as soon as a political issue is mentioned even in passing.
